# 原始预制体关卡配置已恢复

当前六个正式关卡重新使用原始项目的 Chunk 预制体列表。场景的预制体引用、Appearance Count、Spawn Distance、Spawn Offset、Initial Chunk Count 和 Initial Spawn Position 从原始 `Downloads/runner-main.zip` 对应场景恢复；没有覆盖整个场景，也没有改写预制体资源。

## 如何搭建和修改场景

1. 退出 Play Mode，打开 `Assets/Scenes/Start.unity` 至 `Start 6.unity` 中的目标关卡。
2. Hierarchy 搜索并选中 `Chunk Spawner`。
3. Inspector 中展开 `Difficulty Levels`，展开每个元素的 `Chunks`。这里就是原来配置关卡预制体的列表。
4. 双击列表引用的预制体，进入 Prefab Mode。在里面移动地面、平台、障碍和装饰，保存预制体。
5. 返回场景，运行关卡查看。关卡会真正实例化这些预制体，不再根据图片重建另一套地形。

要加入新的关卡块，可以复制一个原有 Chunk 预制体，编辑其内容，再拖进 Chunks 数组。只把预制体放进 Project 文件夹不会自动加入关卡。

## 各字段

| 字段 | 用途 |
| --- | --- |
| Difficulty Levels | 按数组顺序经过的分组 |
| Chunks | 该组按顺序生成的预制体；不是随机权重表 |
| Appearance Count | 该组每个预制体连续出现的次数 |
| Spawn Distance | 相邻 Chunk 根物体的 X 间距；原值为 36，需与你做的块长度匹配 |
| Spawn Offset | 提前加载距离；原值为 25 |
| Initial Chunk Count | 预加载数量；原值按场景分别恢复。运行时仍确保玩家附近地形就绪，支持检查点和读档 |
| Initial Spawn Position | 第一个块的根物体生成位置；原值为 (0, 0) |
| Use Prefab Chunks | 默认开启，使用上述原始预制体；手动关闭才使用之前的程序地形模式 |

系统按分组顺序和 Appearance Count 前进，最后一个有效分组循环，保留原项目的分块制作方式。关卡总路程、阶段结束、心魔与存档仍由人生旅程管理；`LifeJourneySettings` 中的 Target Seconds 和短篇倍率继续决定旅程长度，而不是“到最后一个数组元素就立即通关”。

## 与新系统的关系

- 人生事件仍通过 LifeEventTrigger 的范围和 eventId 控制，三卡、选择历史、存档、预览工具保留；无刷新，暂不执行能力。
- 可以把事件触发器放在场景中，也可以放进 Chunk 预制体；同一个事件 ID 每轮人生只确认一次，不会因块循环重复发放。
- 预制体关卡不会使用 Reserve Flat Ground 覆盖或削平你设计的地形。这个字段只对程序地形模式生效；请把事件触发范围放在你设计的实际地面上。
- 四种战斗心魔继续由独立遭遇管理器管理。原块内旧 Boss、旧 Boss 触发器、旧终点/相机停止流程在实例中隔离，避免与新旅程同时控制游戏；原预制体资产本身不删除这些内容。
- 地面、台阶、坑洞和装饰来自原始预制体，不按年龄自动改写。编辑时需自行检查婴儿爬行、青年无冲刺、中年无二段跳、老年小跳是否能通过原路线。
- 运行时实例会回收并按原预制体类型复用；退出播放后在 Prefab Mode 编辑资产才能保存修改。

## 配置工具

`Chunk Spawner` Inspector 已恢复完整列表编辑，下面保留阶段配置、心魔配置、程序障碍配置的快捷入口。程序障碍权重仅在 Use Prefab Chunks 关闭时生效。

原先会清空预制体列表的迁移已改成 `Life Journey → Sync Stage Art References (Preserve Chunks)`，它只同步美术引用，不再清空场景列表。测试也不会把它们重新清空。

修改预制体后建议先开启短篇运行检查接缝、地面碰撞、抽卡点和心魔。若改了 Spawn Distance，事件点的世界坐标不会自动移动，需要自行检查位置。

命令行验证：`./Tools/Validate-Journey.ps1` 编译并执行逻辑检查；`./Tools/Run-JourneySmoke.ps1 -RenderScreenshots` 在独立副本运行预制体完整流程测试，不回写场景。对应 Unity 入口为 `JourneyPrefabValidation.RunSmoke`，日志成功标记为 `PREFAB RESTORE SMOKE PASSED`。
