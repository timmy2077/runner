# 人生事件与三选一卡牌系统策划案

版本：2.0｜实现范围：触发、选卡、记录与调试；能力效果尚未启用。

关卡来源已恢复原始 Chunk 预制体。默认不重建或削平预制体地形；事件点由作者放在实际可达位置。文中自动保留平地的规则仅适用于可选程序地形模式。

## 1. 核心体验

玩家走进场景中的人生事件触发器，屏幕显示一句人生事件和三张回答卡。选择一张、确认，留下人生经历，再继续跑酷。

青年事件 Y02 示例：“父母又问起了你的婚事，而你也在认真考虑未来。”三个回答是“结婚”“稳事业后再结婚”“不结婚”，分别对应“有人同行”“先立足”“自定人生”。答案与经历固定绑定，没有二次随机。

本版取消刷新事件、转机、刷新奖励、稀有度和技能抽取概率。事件由作者在每个触发器上填写的 eventId 决定，不由运行进度、时间或随机池决定。

能力名称和预期效果保留在配置与卡面中，本版只展示并存档，不改变攻击、速度、跳跃、生命或心魔属性。未来可在选择提交事务之后增加能力聚合模块。

## 2. 关卡布置与触发规则

- 六阶段各三次是推荐主线，共十八次；系统不硬编码事件数量，作者可自由增加、删除、移动或替换事件点。
- 六个正式场景提供三个示例点，分别使用各阶段 01、02、03 事件。04 是可直接使用的额外事件，也可替换已有点。
- 进入 BoxCollider2D 范围后触发。默认等待角色落地；落地前若已离开范围，则本次不打开。可在 Inspector 关闭落地限制。
- 仅当前正式旅程的玩家可以触发；普通物体、敌人、其他场景的事件、阶段不符的事件不能触发。
- 每个事件 ID 每轮人生最多确认一次。同一 ID 放在多个点上，代表同一件经历，不会反复领取。需要两件不同事件时新建不同 ID。
- 多个范围重叠时一次只处理一个，完成后若玩家仍在另一个有效范围内，再处理另一个。
- 没有进入范围就不触发；不会根据 12%、32%、78% 路程自动补弹，也没有婴儿十秒弹窗。
- 不强制玩家完成固定数量的事件才能出关；心魔原有击败门槛继续保留。作者必须保证想要必经的触发范围覆盖角色路线。
- 触发器默认向分段生成器申请附近平地，参数 reserveFlatGround 和 safePadding 可调。该功能不移动触发器，不延长关卡，不改变心魔攻击，也不创建传送点。
- 场景点的位置是世界坐标，标准和短篇不会自动缩放。示例点按短篇长度给出初始位置，因而两种模式均可走到；正式长关可自行移远。超出短篇终点的点在短篇中不可达，应另行布置。

## 3. 界面与流程

进入范围 → 同帧死亡判定结束 → 暂停世界 → 显示事件和三卡 → 选择 → 确认 → 显示结果 → 玩家点击继续 → 可配置倒计时 → 恢复跑酷。

三张卡显示回答、经历名与预期能力。没有默认选择，点击卡牌只是选中，确认才提交；键盘 1/2/3 选择、Enter 确认。确认后必须松开 Enter 再次按下才能继续，避免同一次按键误关闭结果。

横屏三卡并排，竖屏三卡纵排。每张卡内部可滚动长文案。事件界面提供“保存并返回”，没有刷新或跳过按钮。Esc 不绕过事件，切出窗口后不会自动确认或恢复世界。

暂停覆盖移动、物理、普通障碍、心魔、投射物、战斗时间和有效旅程时长。界面交互照常工作。事件触发不清除敌方攻击，恢复后继续原有战斗。

结果页明确显示“经历已记录，能力效果暂未启用”。后续做能力时再替换说明，避免玩家误以为当前已获得数值增强。

## 4. 选择的持久化与叙事

- 触发时保存完整事件和三张卡快照，后续修改事件库不会洗掉已经打开的选择。
- 确认时保存事件 ID、选项 ID、回答、经历名、预期效果、结果文案和叙事标记；重复确认不会创建重复记录。
- 暂停页和结局页可以逐条回看本轮人生选择。
- 保存返回后，进入原阶段并点击开场继续，会恢复待选卡或已确认的结果页，同时回到待选事件的坐标并保留当时速度。
- 完成结果并继续后，普通死亡仍从既有检查点重试；经历不丢失、不重复弹出。事件点本身不会自动创建新检查点。
- 重活一世清空本轮事件和选择。原有 v1 存档缺少事件字段时按空账本兼容，既有阶段、回忆、心魔胜利和死亡数保持。
- Y02 的三条叙事标记 MarryNow、CareerFirst、StayUnmarried 已记录；按婚姻路线改写中年旁白、个性化结局、执行能力、消耗品、收益公式都留到下一阶段实现。

所有人生回答保持平等，不用结婚与否决定好坏结局，不默认玩家有伴侣或子女。
